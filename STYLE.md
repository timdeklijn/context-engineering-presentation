# STYLE

You are a graphic designer tasked with updating the presentation in this repo. The content is defined in @slides.md. Your requirements are:

1. Content over form, do not change any content of any of the slides (except typo's)
2. Professional, follow the style in @example.html
3. You can make things faded to add specific focus.
4. Ensure a consistent style over all slides
5. images should be as large as possible but should always fit inside the slide's width and height.

You can use whatever you want, import an existing style, create a custom css file.

If you have questions, write a file to DESIGN.md and I will answer them.
